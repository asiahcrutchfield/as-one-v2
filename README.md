# AS ONE v2

AS ONE v2 is a small narrative-driven game being developed in Godot.

- `docs/` contains narrative, gameplay, design, and technical documentation.
- `assets/` contains source art, audio, and font assets.
- `scenes/` contains Godot scenes, organized by playable perspective and shared purpose.
- `scripts/` contains GDScript, organized to match the scene structure.
- `resources/` is reserved for Godot resources and game data.
- `scenes/test/` is reserved for isolated gameplay prototypes.

The three perspective identifiers used by the project are `nia`, `antoine`, and `boan`.
